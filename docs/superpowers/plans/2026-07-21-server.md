# par-rt-db Server Implementation Plan (Plan 1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Rust server for par-rt-db — a multi-database, Convex-inspired realtime document DB (declarative query/transaction DSL over WebSocket + HTTP, Postgres storage, GitHub OAuth + machine tokens).

**Architecture:** Single axum/tokio process. Per named database: Postgres schema `db_<name>` with one real table per user table (typed columns for indexed fields), a per-database committer task that serializes writes and drives table-level subscription invalidation, and push-on-change WebSocket subscriptions. Global `rtdb_auth` Postgres schema for users/sessions/allowlists/machine tokens.

**Tech Stack:** Rust (stable, edition 2024), axum 0.8 (ws), tokio, sqlx 0.8 (postgres, runtime-tokio, tls-rustls), serde/serde_json, thiserror, tracing, uuid (v7), sha2 + subtle + rand, reqwest (OAuth), tokio-tungstenite + wiremock + anyhow (dev-deps). Postgres 17 in Docker.

**Spec:** `docs/superpowers/specs/2026-07-21-par-rt-db-design.md` — the authority on protocol and semantics. Plan 2 (TS client + packaging/deploy) is written after this plan completes.

## Global Constraints

- Rust workspace member: `server/` crate named `rtdb-server`. Commit `Cargo.lock`.
- Zero warnings; `cargo clippy --all-targets --all-features -- -D warnings` must pass.
- No `unwrap()`/`expect()` in non-test code paths (tests may).
- Server port **8300**; dev/test Postgres on loopback **55434** (both reserved in `~/.claude/used_ports.md`).
- All wire payloads JSON. Error envelope everywhere: `{"code": "<CODE>", "message": "<text>"}` with codes exactly: `UNAUTHORIZED, FORBIDDEN, NOT_FOUND, SCHEMA_VIOLATION, PRECONDITION_FAILED, BAD_REQUEST, INTERNAL`.
- Database names match `^[a-z][a-z0-9_]{0,32}$`. Table names and field names match `^[a-zA-Z][a-zA-Z0-9_]{0,62}$`; table names must be unique case-insensitively within a schema.
- Doc ids: `uuid::Uuid::now_v7().simple().to_string()` (32 lowercase hex chars). `_creationTime` is epoch **milliseconds** (i64 in storage, JSON number on the wire). Numbers are f64 (`double precision`).
- Secrets (session tokens, machine tokens) are 32 random bytes hex-encoded, stored as SHA-256 hex digests, compared via the digest (never store plaintext). Admin key compared constant-time (`subtle::ConstantTimeEq`).
- Every task ends with its tests passing and an atomic conventional commit. Run tests from `server/` with the dev Postgres up (`make dev-db-up`).
- Integration tests isolate by creating uniquely named rt-db databases (`format!("t{}", Uuid::now_v7().simple())`) inside the shared dev Postgres — never assume exclusive Postgres access, never drop schemas you didn't create.

```rust
#[derive(...)]
#[serde(tag = "type", rename_all = "camelCase", deny_unknown_fields)]
pub enum FieldType {
    String,
    Number,
    Boolean,
    Null,
    Id { table: String },
    Literal { value: serde_json::Value },              // string | number | boolean only
    Optional { inner: Box<FieldType> },
    Union { variants: Vec<FieldType> },
    Array { element: Box<FieldType> },
    Object { fields: std::collections::BTreeMap<String, FieldType> },
}

#[derive(...)]
pub struct IndexDef { pub name: String, pub fields: Vec<String> }

#[derive(...)]
pub struct TableDef {
    pub fields: std::collections::BTreeMap<String, FieldType>,
    #[serde(default)] pub indexes: Vec<IndexDef>,
}

#[derive(...)]
pub struct SchemaDef { pub tables: std::collections::BTreeMap<String, TableDef> }

impl SchemaDef {
    /// Structural validation: identifier regexes (Global Constraints), case-insensitive
    /// table uniqueness, index names unique per table and matching the field-name regex,
    /// index fields exist and are indexable, Literal values scalar, Union non-empty,
    /// reserved field names rejected: any starting with "_" .
    pub fn validate(&self) -> Result<(), RtDbError>;
    pub fn table(&self, name: &str) -> Result<&TableDef, RtDbError>;    // NotFound
}

impl TableDef {
    pub fn index(&self, name: &str) -> Result<&IndexDef, RtDbError>;    // BadRequest if missing
}

/// Column type for an indexed field. Indexable types: String→"text", Number→"double precision",
/// Boolean→"boolean", Id→"text", Literal(string)→"text", Union where every variant is
/// Literal(string)→"text". Optional<indexable> → (pg_type, nullable=true). Anything else → Err.
pub fn indexed_column_type(ty: &FieldType) -> Result<(&'static str, bool), RtDbError>;

/// Full-document validation: every schema field present-and-valid (Optional may be absent),
/// no unknown fields, no "_"-prefixed fields. Errors are SchemaViolation naming the field path.
pub fn validate_doc(table: &TableDef, doc: &serde_json::Map<String, serde_json::Value>) -> Result<(), RtDbError>;

/// Validate a single value against a type (recursive; used by validate_doc and patch).
pub fn validate_value(ty: &FieldType, value: &serde_json::Value) -> bool;
```

- Consumes: `RtDbError` from Task 2.
- Semantics that later tasks rely on: `Optional` accepts absent **or** `null` (and `null` means "unset" when patching); `Number` accepts any JSON number; `Id` is validated as a 32-lowercase-hex string (referential existence is NOT checked in MVP); `Union` matches if any variant matches; `Literal` matches by strict equality.

```rust
// ddl.rs
/// Validates new schema (SchemaDef::validate), loads previous from meta, rejects destructive
/// changes (removed table/field/index, changed field type, changed index fields) with
/// BadRequest naming the offender. Applies additive DDL in ONE transaction:
/// per new table: CREATE TABLE "db"."t_<lower>" (id text primary key, doc jsonb not null,
///   created_at bigint not null, version bigint not null default 1 [, f_<lower> <pgtype> [null]]…);
/// per new indexed field on existing table: ALTER TABLE ADD COLUMN f_x <pgtype>, then
///   UPDATE … SET f_x = (doc->>'x')::<cast> WHERE doc ? 'x';
/// per new index: CREATE INDEX "i_<table>_<index>" ON … (f_a, f_b, created_at);
/// finally upserts meta 'schema'. Returns the applied SchemaDef.
pub async fn push_schema(pool: &PgPool, db: &str, schema: SchemaDef) -> Result<SchemaDef, RtDbError>;

pub fn pg_table(user_table: &str) -> String;   // "t_" + lowercase
pub fn pg_col(field: &str) -> String;          // "f_" + lowercase
pub fn pg_schema(db: &str) -> String;          // "db_" + name

// admin.rs — routes merged into build_router:
// POST /admin/create-db   {"name": "..."}                    -> {"ok": true}
// POST /admin/push-schema {"db": "...", "schema": {…}}       -> {"ok": true}
// GET  /admin/dbs                                            -> {"databases": ["..."]}
// (allowlist + token routes are Task 8)
```

```rust
    Patch   { table: String, id: String, fields: serde_json::Map<String, serde_json::Value> },
    Delete  { table: String, id: String },
    ExpectVersion { table: String, id: String, version: i64 },
    ExpectAbsent  { table: String, index: String, eq: Vec<serde_json::Value> },
    Upsert  { table: String, index: String, eq: Vec<serde_json::Value>,
              insert: serde_json::Map<String, serde_json::Value>,
              patch: serde_json::Map<String, serde_json::Value> },
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct Transaction { pub steps: Vec<Step> }

#[derive(Debug, Clone, serde::Serialize)]
#[serde(untagged)]
pub enum StepResult {
    Insert { id: String },
    Upsert { id: String, inserted: bool },
    None,                                   // serialized as null via custom impl — use Option instead if simpler
}

#[derive(Debug, Clone, serde::Serialize)]
pub struct TxnOutcome {
    pub results: Vec<serde_json::Value>,    // per step: {"id":..}, {"id":..,"inserted":..}, or null
    pub write_set: std::collections::BTreeSet<String>,  // user table names touched by writes
}

/// Executes all steps in one sqlx Postgres transaction; any error rolls back.
/// Max 256 steps (BadRequest). Validates docs/fields against schema during execution.
pub async fn execute_txn(pool: &PgPool, db: &str, schema: &SchemaDef, txn: &Transaction)
    -> Result<TxnOutcome, RtDbError>;
```

- Consumes: Tasks 2–4 (`pg_schema/pg_table/pg_col`, `new_id`, `now_ms`, `validate_doc`, `validate_value`, `indexed_column_type`).
- Execution semantics (later tasks and the TS client rely on these exactly):
  - **Insert**: `validate_doc`; id = `new_id()`; `created_at = now_ms()`; INSERT with doc jsonb + every indexed-field column extracted from the doc (absent optional → NULL). Result `{"id": id}`.
  - **Patch**: SELECT doc by id (NotFound if missing). For each field in `fields`: must exist in schema (SchemaViolation otherwise); value `null` on an `Optional` field whose inner doesn't accept null → **remove** the field; else `validate_value` then set. `validate_doc` the merged result. UPDATE doc, all indexed columns, `version = version + 1`. Result `null`.
  - **Delete**: DELETE by id; NotFound if zero rows. Result `null`.
  - **ExpectVersion**: SELECT version by id; NotFound if missing; mismatch → PreconditionFailed `"version mismatch: expected {e}, actual {a}"`. Result `null`.
  - **ExpectAbsent**: index lookup (eq binds must cover ALL index fields, typed per schema — BadRequest otherwise); any row → PreconditionFailed. Result `null`.
  - **Upsert**: same full-eq index lookup; 0 rows → behave as Insert of `insert` doc, result `{"id":id,"inserted":true}`; 1 row → behave as Patch of `patch` fields on it, result `{"id":id,"inserted":false}`; >1 rows → PreconditionFailed `"upsert matched multiple documents"`.
  - Eq-value → SQL bind typing: resolve each index field's `FieldType` (unwrap Optional): String/Id/Literal-or-union-of-string-literals → bind `&str`; Number → `f64`; Boolean → `bool`. JSON value of the wrong shape → BadRequest.
  - `write_set` contains tables touched by Insert/Patch/Delete/Upsert (not by pure preconditions).
